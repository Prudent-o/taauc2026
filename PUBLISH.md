# Publish Notes

This directory is ready to be published as a static GitHub Pages site.

Recommended repository name:
- `taauc2026`

Recommended URL:
- `https://prudent-o.github.io/taauc2026/`

Files used for direct static hosting:
- `index.html`
- `assets/css/main.css`
- `assets/css/taauc.css`

The site now uses a single-page structure with section anchors.
Legacy subpages remain only as redirect stubs to the matching section on `index.html`.

Typical publish steps when network is available:
1. Create a new GitHub repository.
2. Add the remote: `git remote add origin https://github.com/Prudent-o/taauc2026.git`
3. Commit the current files.
4. Push the default branch.
5. In GitHub Pages, set the source to `Deploy from a branch`, branch `main`, folder `/ (root)`.
