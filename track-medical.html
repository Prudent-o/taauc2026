Medical Agent Track

This page fixes the scope of the medical track without inventing details that are still under discussion.

  1. Home
  2. Tracks
  3. Medical Agent

Planned focus

  • Safe execution in medical or health-related workflows
  • Reliable reasoning under higher safety expectations
  • Protocol compliance, escalation, and abstention behavior
  • Error handling when the agent should stop or ask for help

Expected evaluation axes

  • Task completion quality
  • Safety and risk-aware behavior
  • Consistency with required constraints
  • Robustness to difficult and ambiguous cases

Likely submission forms

Agent systems, safety monitoring layers, intervention modules, or evaluation methods tailored to medical-agent workflows.

What will be added later

The final task description, data or interaction interface, baseline package, and exact scoring protocol will be added when the track proposal is complete.

Status: confirmed track, final task package pending.
