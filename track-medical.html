Medical Agent Track

This page is the placeholder entry for the medical agent track. The detailed technical proposal has not been released yet, but the page already separates the track from the rest of the site so that later updates can stay local to this track.

Planned focus

  • Safe task execution in medical or health-related workflows
  • Reliable reasoning under higher safety expectations
  • Protocol compliance and appropriate intervention behavior
  • Error handling, abstention, and escalation when needed

Expected evaluation dimensions

  • Task success and workflow completion quality
  • Safety and risk-aware behavior
  • Consistency with required medical or clinical constraints
  • Robustness to difficult, ambiguous, or failure-prone cases

Likely participant submissions

Agent systems, action monitoring layers, safety intervention modules, verification or validation components, or track-specific evaluation methods.

What will be published later

Task definition, dataset scope, interaction interface, baseline package, submission format, and exact scoring protocol.

Status. Confirmed track. Full task specification is pending the final proposal from the track team.
