Track 1

Medical Agent Track

This page is public before the final task package is released. It fixes the track identity and the main evaluation direction while leaving room for the exact benchmark design that will follow.

Current focus

The track will study trustworthy agent behavior in medical workflows. We expect the final task design to involve safety-sensitive interactions where an agent must remain useful, clinically appropriate, and rule-consistent.

Public placeholder scope

The final proposal has not yet been delivered. This page therefore keeps the scope broad on purpose and avoids claiming specific datasets, interfaces, or metrics that have not been finalized.

Likely task shape

  • Medical or health-related agent workflows.
  • Action planning under safety constraints.
  • Handling of exceptions, uncertainty, and escalation.

Likely evaluation dimensions

  • Task success and response quality.
  • Safety and protocol compliance.
  • Error handling and robustness.
  • Utility retention after safety controls.

What will be added later

  • Task definition and interaction interface.
  • Data description and licensing notes.
  • Official metrics and scoring code.
  • Starter kit, baseline, and submission instructions.
