Track Structure

The final technical proposals are still pending, so the current language stays at the right level: it states each track focus clearly without pretending that the exact benchmark package is already final.

Track 1

Medical Agent Track

This track studies trustworthy agent behavior in medical workflows. The final proposal has not been released yet, so the public page keeps the scope broad and accurate.

  • Planned focus: safe task execution, reliable reasoning, and clinically appropriate behavior.
  • Likely submissions: agent systems, safety monitors, verification layers, or track-specific evaluation methods.
  • Evaluation dimensions: task quality, safety, protocol compliance, error handling, and robustness.

Track 2

Text Privacy Compliance Track

This track studies compliant handling of private information in text. It is aimed at systems that must protect sensitive content while keeping required utility.

  • Planned focus: privacy-sensitive text processing and compliance-aware transformation.
  • Likely submissions: agent workflows, redaction systems, rewriting pipelines, and validation modules.
  • Evaluation dimensions: privacy protection, compliance quality, utility retention, consistency, and robustness.
